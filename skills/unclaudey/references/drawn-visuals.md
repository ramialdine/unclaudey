# Code-drawn visuals: SVG and canvas that belong to the subject

The best code-drawn visuals in our A/B (the ceramics pot shelf and the reshapeable pot, the bouldering holds and the mill drawing) shared five traits. Aim for all of them:

1. **Real geometry from the subject.** A pot comes from a lathe profile, a climbing hold is an organic blob with a bolt hole, and a mill has its real sawtooth roofline. Never use a generic icon when you can draw the actual thing.
2. **One rendering style.** Use flat fills, one light direction (a highlight on the top-left), and one stroke weight. Add a quiet material texture (clay speckle, chalk, paper grain) at 3–6% opacity. Consistency is what makes it look designed rather than generated.
3. **Colors only from the palette.** Use the `--color-*` tokens from `palette`, plus shades of them. `sheet drawings` flags colors that aren't in the palette.
4. **Drawings carry information.** For example: the course weeks as a sequence of pots, each seconds pot drawn with its actual flaw, the grade distribution as colored holds. Decoration alone is a tell of generated design.
5. **Generated by a small script, not typed by hand.** Write a short generator (JS in the page, or a one-off Node or Python script) that outputs the SVG. That gives you smooth curves, consistent variation (a seeded random generator) and easy tweaks.

## Building blocks (copy, then adapt)

```js
// Seeded random numbers: the same drawing every render
function rng(seed) { return () => { seed |= 0; seed = seed + 0x6D2B79F5 | 0;
  let t = Math.imul(seed ^ seed >>> 15, 1 | seed); t = t + Math.imul(t ^ t >>> 7, 61 | t) ^ t;
  return ((t ^ t >>> 14) >>> 0) / 4294967296; }; }

// Smooth closed/open path through points (Catmull-Rom → cubic Bézier)
function smooth(pts, closed = true) {
  const n = pts.length, P = i => pts[(i + n) % n];
  let d = `M${P(0)[0].toFixed(1)} ${P(0)[1].toFixed(1)}`;
  const last = closed ? n : n - 1;
  for (let i = 0; i < last; i++) {
    const [p0, p1, p2, p3] = [P(i - 1), P(i), P(i + 1), P(i + 2)];
    const c1 = [p1[0] + (p2[0] - p0[0]) / 6, p1[1] + (p2[1] - p0[1]) / 6];
    const c2 = [p2[0] - (p3[0] - p1[0]) / 6, p2[1] - (p3[1] - p1[1]) / 6];
    d += ` C${c1.map(v => v.toFixed(1)).join(' ')} ${c2.map(v => v.toFixed(1)).join(' ')} ${p2.map(v => v.toFixed(1)).join(' ')}`;
  }
  return closed ? d + 'Z' : d;
}

// Lathe profile → vessel silhouette (pots, vases, bottles, lamps, cups)
// profile: [height 0..1 from foot to rim, radius 0..1]
function vessel(profile, w = 160, h = 200) {
  const cx = w / 2, right = profile.map(([y, r]) => [cx + r * w / 2, h - y * h]);
  const left = right.map(([x, y]) => [2 * cx - x, y]).reverse();
  return smooth([...right, ...left]);
}
// bowl: vessel([[0,.3],[.08,.36],[.45,.7],[.85,.92],[1,.95]])   vase: vessel([[0,.34],[.3,.62],[.62,.56],[.82,.26],[1,.34]])

// Organic blob (climbing holds, pebbles, fruit, stains)
function blob(seed, r = 40, points = 9, wobble = .25, squash = .8) {
  const rand = rng(seed);
  return smooth(Array.from({ length: points }, (_, i) => {
    const a = i / points * Math.PI * 2, k = 1 + (rand() * 2 - 1) * wobble;
    return [Math.cos(a) * r * k, Math.sin(a) * r * k * squash];
  }));
}
```

**Shading and texture, kept consistent:**
```html
<defs>
  <!-- one light direction for every object on the page: highlight top-left -->
  <linearGradient id="form" x1="0" y1="0" x2="1" y2="1">
    <stop offset="0" stop-color="var(--color-accent-2)"/><stop offset="1" stop-color="var(--color-accent)"/>
  </linearGradient>
  <!-- material texture: speckle (clay), chalk, grain; low opacity -->
  <pattern id="speckle" width="24" height="24" patternUnits="userSpaceOnUse">
    <circle cx="3" cy="5" r=".8" fill="var(--color-ink)" opacity=".18"/><circle cx="15" cy="11" r=".6" fill="var(--color-ink)" opacity=".14"/>
    <circle cx="9" cy="19" r=".7" fill="var(--color-ink)" opacity=".16"/>
  </pattern>
</defs>
<path d="…vessel…" fill="url(#form)"/><path d="…same…" fill="url(#speckle)"/>
<ellipse cx="…" cy="…" rx="…" ry="…" fill="#fff" opacity=".18"/> <!-- highlight -->
```
CSS custom properties work inside inline SVG, so `var(--color-*)` keeps drawings on-palette and makes dark mode free.

## Techniques by subject
- **Vessels and turned objects** (ceramics, glass, coffee, candles): `vessel()`, a speckle pattern, a rim ellipse and a foot ring.
- **Organic objects** (holds, stones, produce, cheese): `blob()` with a seed per object, a bolt hole or stem, and a soft shadow ellipse under it.
- **Architecture and places** (mills, cafés, venues, maps): a line drawing with one stroke width (`vector-effect: non-scaling-stroke`). Repeated windows go in a `<symbol>` + `<use>`. Label it like a plan, with small and legible labels.
- **Process and sequences:** the same object at successive states (lump → cylinder → bowl → trimmed → glazed) lined up as a timeline.
- **Data:** draw it in the subject's material (grade counts as stacks of holds, currencies as coins) with real numbers.
- **Paper-cut and layered:** 3–5 stacked shapes in palette tones, with a small offset shadow (`filter: drop-shadow(0 2px 0 rgb(0 0 0 / .15))`).
- **Hatching and stipple:** `<pattern>` lines or dots for shadow in line-art styles.

## The one live object (canvas)
Use `scripts/engine/snippets/live-object.js`. It already handles:
- sharp rendering on high-density screens and resizing
- pointer, touch and keyboard input, with a focusable canvas
- pausing when offscreen or when the tab is hidden
- one intro animation, skipped when motion is reduced
- a static SVG fallback shown until JavaScript runs

Keep the object's physics simple and satisfying. Dragging reshapes or rotates it, and the arrow keys do the same. Give it a visible hint ("Drag across the clay to shape it") and a reset button.

## Accessibility and weight
- **Meaningful drawings** get `role="img"` and an `aria-label` (or `<title>`). Decorative ones get `aria-hidden="true"`.
- **Text inside SVG** must be at least 12px at phone width. `sheet drawings` flags anything under 10px.
- **Size:** keep each inline SVG under about 30 KB. Reuse shapes with `<symbol>`, and round coordinates to 1 decimal.

## Check it
Run `unclaudey.py sheet drawings --page index.html` and look at the sheet. Ask:
- Is every drawing specific to this subject?
- Is the style consistent (weight, texture, light)?
- Is it legible on a phone?
- Are the colors from the palette?
